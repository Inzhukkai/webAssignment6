## Открыть в VS Code

1. Распакуйте ZIP. Откройте папку с index.html, team.html, contact.html, style.css и script.js.
2. Сохраните резервную копию старого проекта. Замените файлы проекта файлами из этой папки, включая JSON и папку vendor. Каждый HTML — отдельный файл; не объединяйте три документа в один.
3. В VS Code запустите index.html через Live Server (Open with Live Server). Либо в терминале папки проекта выполните `python -m http.server 5500`, затем откройте http://localhost:5500.
4. Не запускайте двойным щелчком как file://: загрузка JSON требует HTTP-сервера.

## Проверки

Синтаксис script.js и локальные зависимости HTML проверяются отдельно. Логику заданий проверяли в DOM-эмуляторе с имитацией размеров видимой области; это не заменяет визуальную проверку в браузере. Перед сдачей пройдите таблицу выше в Chrome на компьютере и телефоне.

Форма рассылки — имитация без реальной подписки. Contact отправляет данные в демонстрационный JSONPlaceholder API, а не на почту команды. Для копирования нужен HTTPS или localhost и разрешение браузера. Фото загружаются с внешних сайтов; их доступность зависит от этих сайтов.

## Публикация (Part 4)

1. Замените файлы в своём существующем репозитории PrincessDreamland-Assignment6.
2. В Source Control VS Code проверьте изменения, выполните Commit и Sync/Push. Не удаляйте папку .git.
3. На GitHub проверьте Settings → Pages: нужная ветка и папка / (root).
4. Дождитесь завершения публикации в Actions. Откройте https://inzhukkai.github.io/PrincessDreamland-Assignment6/ и обновите Ctrl+F5.
5. Повторите таблицу заданий на опубликованном сайте. Новая версия должна показывать Copy Fact и Our Little World.
